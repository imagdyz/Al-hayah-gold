# الحياة جولد — Al Hayah Gold

موقع وتطبيق موبايل لمحل ذهب حقيقي ليه فروع:

- **سبائك وجنيهات بسعر اللحظة:** تتطلب أونلاين، والسعر بيتثبّت وقت الطلب، والاستلام من الفرع.
- **مجوهرات موجودة فعلاً في المحلات:** العميل يشوف القطعة في أنهي فرع ويحجزها قبل ما ينزل.
- **بيع أو تبديل الذهب القديم:** بمعاد في الفرع وبسعر اللحظة.

> مفيش محفظة ولا رصيد ذهب جوه التطبيق. العميل مش بيخزّن ذهب عندنا، وكل طلب بيتقفل باستلام من الفرع.

### الهوية

**الألوان:**

| اللون | الكود |
| --- | --- |
| حبر | `#12100C` |
| ذهب | `#C8A04B` |
| ذهب فاتح للنصوص على الغامق | `#E6C77A` |
| ذهب داكن للنصوص على الفاتح | `#8A6A1F` |
| كريمي | `#F1E6CC` |
| خلفية | `#F6F3EE` |
| خطوط | `#ECE5D8` |
| صعود | `#1F7A4D` |

**الخطوط:** العناوين بـ **El Messiri**، والنصوص والأرقام بـ **IBM Plex Sans Arabic**.

**العلامة:** نجمة ثمانية من الزخرفة الإسلامية حوالين دايرة زي الخاتم. النجمة دي بتتكرر كنقشة خفيفة في الأجزاء الغامقة، وكدلاية في السلسلة.

**العمق:**
- الأجزاء المهمة على حبر بإضاءة دافية.
- الكروت بس للحاجات اللي بتتداس، وبظل دافي.
- الأزرار الأساسية بتدرّج ذهبي ولمعة خفيفة.

### صور المنتجات

صور السبائك والجنيه والمجوهرات **صور 3D توضيحية**، معمولة بـ three.js وخامة ذهب واقعية. لازم تتبدّل بتصوير حقيقي من المحل قبل الإطلاق.

السكريبت في [`tools/renders/`](tools/renders/):

```bash
cd tools/renders && npm install && npm run render       # كل الصور في out/
npm run render -- bar10 coin                             # صور معينة
```

> كل الأسعار والأوزان أرقام توضيحية. أي نص بين `[ ]` محتاج بيانات حقيقية، زي:
> - أسماء الفروع وعناوينها
> - المصنعية
> - مدة تثبيت السعر
> - نسبة العربون
> - بيانات الترخيص
